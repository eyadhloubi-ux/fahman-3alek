# فهمان عليك؟ · قعدة رواق

لعبة للقعدات من مشروع «صار بدها قعدة.» — إعداد م. إياد حلوبي.

سؤال عن واحد منكن، الكل بيكتبلو جوابو بورقة مطوية، وهو بيختم أقرب 3 أوراق إلو: أول ورقة بتاخد نقطتين، والتنتين اللي بعدها نقطة لكل وحدة. الريس بيحدّد عدد الدورات من الأول، وبكل دورة بيوصل الدور لكل واحد مرة. وبالآخر بيطلع الترتيب: مين «قارئ الأفكار» ومين «مو فهمان على حدا».

---

## شو في جوّا الحزمة

| الملف | شو هو |
|---|---|
| `server.js` | السيرفر: بيمرّر الرسائل بين الموبايلات، وصفحة الإحصائيات |
| `public/` | اللعبة نفسها (الصفحة، التصميم، الخطوط، الأيقونات) |
| `render.yaml` | إعدادات النشر الجاهزة على Render |
| `package.json` + `package-lock.json` | المكتبات اللي بيحتاجها السيرفر |
| `Dockerfile` + `.dockerignore` | بديل جاهز إذا بدك تنشر كـ Docker |
| `.node-version` | نسخة Node (20) لـ Render |
| `.gitignore` | الملفات اللي ما لازم تنرفع |

## 1) الرفع على GitHub

1. فك ضغط الملف `fahman-3alek.zip` على جهازك. رح يطلعلك مجلد فيه الملفات مباشرة (`server.js`، `package.json`، `render.yaml`، `public`…).
2. ادخل على [github.com](https://github.com) واعمل **New repository**:
   - الاسم مثلاً: `fahman-3alek`
   - خليه **Public** أو **Private**، الاتنين بيمشوا.
   - لا تضيف README (موجود عندك).
3. بصفحة المستودع الجديد اكبس **uploading an existing file**.
4. افتح المجلد، **حدّد كل اللي جوّاه** (Ctrl+A أو ⌘+A) واسحبهن لصفحة GitHub. **لا تسحب المجلد نفسه.**
5. اكبس **Commit changes**.
6. ✅ **تأكد:** بالصفحة الرئيسية للمستودع لازم تشوف `server.js` و`package.json` و`render.yaml` ومجلد `public` **مباشرة**، مو جوّا مجلد تاني.
   - الملفات اللي اسمها بيبلّش بنقطة (`.gitignore`، `.node-version`، `.dockerignore`) ممكن تكون مخفية عندك. على الماك اكبس ⌘+Shift+. لتبين. وإذا ما انرفعت ما في مشكلة، مو ضرورية.

> **إذا كان عندك المستودع القديم:** امسح الملفات القديمة أول، أو اعمل مستودع جديد، لأن إذا كان في مجلد `fahman-3alek` جوّا المستودع Render ما بيلاقي الملفات.

## 2) النشر على Render

1. ادخل على [render.com](https://render.com) وسجّل دخول بحساب GitHub.
2. من فوق اكبس **New +** ثم **Blueprint**.
3. اختار المستودع `fahman-3alek` واكبس **Connect**.
4. Render رح يقرأ ملف `render.yaml` لحالو. اكبس **Apply**.
5. استنّى لحد ما يصير **Live** (دقيقتين تقريباً).
6. الرابط بيطلع بأعلى الصفحة، شي متل: `https://fahman-3alek.onrender.com`

> إذا بتحب تعملها يدوي بدل Blueprint: **New + ← Web Service**، اختار المستودع، وحط:
> - Build Command: `npm install`
> - Start Command: `npm start`
> - وبقسم Environment ضيف متغيّر اسمه `STATS_KEY` وقيمته أي كلمة سر بتختارها.

## 3) الروابط

| الرابط | لشو |
|---|---|
| `https://…onrender.com` | اللعبة، هاد اللي بتحطو بالـBio |
| `https://…onrender.com/?demo=1` | **جرّب لحالك**: لاعبين وهميين بيلعبوا معك |
| `https://…onrender.com/stats?key=…` | الإحصائيات (أرقام بس، بلا أسماء) |

**مفتاح الإحصائيات:** بـRender افتح الخدمة ← **Environment** ← انسخ قيمة `STATS_KEY` وحطها بالرابط بعد `key=`.

## 4) ملاحظات مهمة

- **وقت انتظار الريس:** افتراضياً 40 ثانية. إذا بدك تغيّره ضيف بـRender متغيّر `HOST_GRACE_MS` بالميلي ثانية (مثلاً `60000` لدقيقة).
- **الكاميرا (السيلفي)** بتشتغل بس على رابط `https` (وRender بيعطيك هيك تلقائياً). إذا المتصفح منع الكاميرا، اللعبة بتفتح كاميرا الموبايل العادية بدالها.
- **الخطة المجانية بتنام:** إذا ما حدا فتح اللعبة 15 دقيقة، أول فتحة بعدها بتاخد حوالي دقيقة لتصحى. الحل: افتح الرابط قبل القعدة بشوي، أو رقّي الخطة لـ Starter.
- **الإحصائيات بتنمسح مع كل نشر جديد** بالخطة المجانية لأنها بتنحفظ بملف. إذا بدك تحفظها للأبد:
  1. بـRender اعمل **New + ← PostgreSQL** (في خطة مجانية).
  2. انسخ **Internal Database URL**.
  3. ضيفو بالخدمة كمتغيّر اسمه `DATABASE_URL`. السيرفر بيلقطو لحالو.
- **التحديث:** أي تعديل بترفعو على GitHub، Render بينشره لحالو.

## 5) إذا Render رفض أو طلع خطأ

افتح الخدمة بـRender ← **Logs**، وشوف أول سطر أحمر:

| الرسالة | السبب والحل |
|---|---|
| `No render.yaml found` أو ما بيطلع شي بالـBlueprint | الملفات جوّا مجلد بالمستودع. ارفعها بأول المستودع (الخطوة 4 فوق). |
| `ENOENT: no such file or directory, open '.../package.json'` | نفس السبب: `package.json` لازم يكون بأول المستودع. |
| `Root Directory` مكتوب فيه شي | بإعدادات الخدمة ← **Settings** ← فضّي خانة **Root Directory**. |
| `Exited with status 1` بعد `npm install` | تأكد إن **Build Command** هو `npm install` و**Start Command** هو `npm start`. |
| `Port scan timeout` / `No open ports detected` | تأكد إن **Start Command** هو `npm start` (مو `node index.js`). |
| الـBlueprint بيقول الخطة مو متاحة | بدّل `plan: free` لـ `plan: starter` بملف `render.yaml`، أو اعملها يدوي كـ Web Service. |

**طريقة بديلة (Docker):** New + ← Web Service ← اختار المستودع ← بخانة **Language** اختار **Docker**. الـ`Dockerfile` جاهز وما بدّك تكتب أي أمر.

## 6) التشغيل على جهازك (اختياري)

بدك [Node.js](https://nodejs.org) نسخة 18 أو أحدث:

```bash
npm install
npm start
```

وافتح `http://localhost:3000`. لتجرّب كذا لاعب، افتح الرابط بكذا نافذة أو من موبايلك على نفس الشبكة.

## كيف بتنلعب (بالمختصر)

1. **الريس** بيفتح الرابط ← «افتح قعدة جديدة» ← بيطلعلو QR وكود من 5 أحرف.
2. الباقي بيمسحوا الكود، بيكتبوا اسمهن (اختياري)، بياخدوا **سيلفي** أو بيختاروا صورة، وبيختاروا شب أو صبية. وقبل ما نبلّش كل واحد بيقدر يعدّل اسمو وصورتو.
3. الريس بيختار:
   - **كم دورة** (من 1 لـ 6): كل واحد بيوصلو الدور مرة بكل دورة.
   - **كم سؤال من البنك** لكل واحد، والباقي كل واحد بيكتبو عن حالو من موبايلو قبل ما نبلّش (واللي ما لحّق بيكتبو لما يجي دورو).
   - **أسماء أصحاب الأوراق:** بتبين بالكشف أو مخفية.
   - **وقت الكتابة:** مفتوح، أو 30 / 60 / 90 ثانية بكل دور.
   - **الأعضاء:** بيكبس على أي حدا ليعدّل اسمو، أو يطلّعو من القعدة، أو يسلّمو الرياسة.
4. بكل دور: سؤال عن شخص ← الكل بيكتب ← صاحب الدور بيختم أقرب 3 أوراق: الأولى نقطتين، والتنتين بعدها نقطة نقطة (وإذا اختار ورقة وحدة بتاخد نقطتين). إذا في أجوبة نفس بعض بس مكتوبة غير شكل، **ضغطة مطوّلة** على الورقة بتحطها كمان بالمركز الأول (نقطتين لكل وحدة). وزر «ولا حدا فهمان عليّ» صار مفصول تحت الأوراق، وبيطلب تأكيد.
5. أدوات الريس: ⏱ «20 ثانية وبنسكّر»، «سكّر الصندوق»، «مرّر السؤال»، «تخطّى الدور»، «افتح الظرف» أو «خبّيه للآخر».
6. بين الدورات النقاط بتتجمّع، وبآخر دورة: «يلا عالنتيجة» أو «دورة زيادة» ← نوع القعدة (أو نوع بتكتبوه إنتو) واسمها (إجباري) وصورتها أو سيلفي جماعي (اختيارية) ← حفلة كشف أو دفعة وحدة.
7. **إذا الريس طلع:** اللعبة ما بتوقف ولا بتنمسح. منستناه 40 ثانية، وبعدها أي حدا من القعدة بيقدر يكبس «أنا بستلم» ويكمّل من موبايلو من نفس المكان. وإذا رجع الريس القديم بيرجع لاعب.
8. النتيجة: الترتيب مع لقب لكل واحد، كل الجولات، وصورة ستوري جماعية فيها ترتيب الكل، والشخص اللي بتختارو بيطلع مميّز (غلاف / بولاريد / طابع، فاتح أو داكن). وبالآخر زر «نزّل تطبيق اللعبة» مع خطوات لكل موبايل.
9. زر **؟** فوق بكل الشاشات بيفتح «كيف منلعب؟».
